tests/chapter-10/10.6.2--force-release.sv	force / release are procedural CONTINUOUS ASSIGNMENTS with no synthesis semantics. The module is a flop (always @(posedge clk) q <= d) that an always @(f1 or f0) block forces to 0 or 1 and releases. Verilator honours the force on the RTL side and no netlist can represent it, so every cycle with f0 or f1 high diverges by construction. read_slang refuses the file outright ("Design elaboration failed"), so there is no reference to adjudicate against either. Neither frontend is wrong.
